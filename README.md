# 🌟 DishaConnect

> **Your Direction, Our Guidance**

DishaConnect is an AI-powered guidance and astrology platform developed using **Django**. It provides users with personalized guidance in career, education, business, personal life, and astrology through a secure interaction between users, AI, and verified human guides.

---

## 📖 Project Overview

DishaConnect is designed to bridge the gap between users seeking guidance and trusted mentors while ensuring privacy and security. The platform combines Artificial Intelligence with expert human guidance and astrology to provide meaningful and reliable suggestions.

## 💻 Installation

Clone the repository

```bash
git clone https://github.com/parnikamaheshwari7-png/DishaConnect.git
```

Move into project directory

```bash
cd DishaConnect
```

Create Virtual Environment

```bash
python -m venv venv
```

Activate Virtual Environment

Windows

```bash
venv\Scripts\activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run migrations

```bash
python manage.py migrate
```

Create Superuser

```bash
python manage.py createsuperuser
```

Run the project

```bash
python manage.py runserver
```

Visit

```
http://127.0.0.1:8000/
```
